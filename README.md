# HomeMesh Mobile UX Demo

팀 아이디어 공유용 클릭형 모바일 UI 프로토타입입니다.

## 실행

가장 간단한 방법은 `index.html`을 Chrome에서 직접 여는 것입니다.

권장 데모 방식:
1. Chrome에서 `index.html` 열기
2. F12 → Device Toolbar
3. viewport를 `390 × 844`로 설정
4. 온보딩을 따라가거나 설정 완료 후 메인 화면 오른쪽 아래 `▶` 버튼으로 Context Handoff 시연

- 4개 Home Module 페어링 및 공간 배치
- 카메라 시야 보정
- 가족/사용자 등록
- 얼굴 등록 및 Context Handoff 테스트
- 목소리 등록

- 기상/취침 밴드, 선호 온도, 수면 시 자동화 설정
